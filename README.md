# 🌱 Tealand - Fresh from our tea gardens to your cup

## 📖 Description

Tealand is a website dedicated to tea, designed to showcase its variety, unique blends, and health benefits. This project combines a modern design with functional elements.

---

## 🚀 Key Features

- Interactive **slider for unique tea blends**.
- Sections highlighting product benefits, best menu, and brand story.
- Image gallery with large and small sliders.
- Dynamic buttons and responsive layout.

---

## 🛠️ Technologies Used

- **HTML**: Website structure.
- **CSS**: Styling elements and ensuring responsiveness.
- **JavaScript**: Dynamic components (sliders, buttons).
- **Swiper.js**: Implementation of carousels and sliders.
- **BEM Methodology**: Organizing CSS classes.

---

## 🖼️ Website Sections

1. **Hero**: Main block with a welcome message and "Explore" button.
2. **Advantages**: Section highlighting the health benefits of tea.
3. **Choose Us**: Why choose us – three key characteristics.
4. **Unique Blends**: Interactive slider for unique tea blends.
5. **Best Menu**: Top drinks with prices.
6. **Good Cap**: Organic, high-quality, and always fresh products.
7. **Gallery**: Image gallery showcasing tea varieties.

---

## 📦 How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/username/tealand.git
   ```
2. Open the index.html file in your browser.
3. Enjoy browsing the website!
